# Idle AI Path Walker

A Unity experiment demonstrating an AI-controlled character
automatically following a predefined route.

## Features

- Predefined waypoints
- Automatic movement
- Movement between path positions
- Idle NPC behaviour

## Running the project

1. Open Unity Hub.
2. Select Add project from disk.
3. Select this project's folder.
4. Open the demonstration scene.
5. Press Play.

## Status

Functional AI navigation experiment.
