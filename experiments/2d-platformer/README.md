# 2D Platformer Experiment

A Unity prototype created to practise player movement, goal detection
and moving between stages.

## Features

- 2D player movement
- Collision detection
- End-of-level goal
- Progression to the next stage

## Running the project

1. Open Unity Hub.
2. Select Add project from disk.
3. Select this project's folder.
4. Open the main scene.
5. Press Play.

## Status

Functional technical prototype.
