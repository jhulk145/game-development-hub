# Game Development Hub

Welcome to my game-development portfolio. This repository brings together a selection of games, Unity prototypes, technical experiments, and 3D assets I have created while developing my programming and game-design skills.

## Featured Games

### Flappy Bird Recreation

A recreation of the classic *Flappy Bird* gameplay loop. The player controls a flying character and must navigate through pipes that spawn at varying heights.

<img width="1311" height="512" alt="image" src="https://github.com/user-attachments/assets/66818e1a-5a50-4d59-a29f-9a2980f2cfa7" />


**Technologies:** Unity, C#

**Key features:**

* Player movement and input
* Procedurally positioned obstacles
* Collision detection
* Score-based gameplay

[View the Flappy Bird repository](https://github.com/jhulk145/flappy-bird)

### Bounty

A futuristic 3D platformer featuring custom wall-running mechanics, ranged combat, and enemy encounters. Players move between walls and platforms while fighting enemies throughout the environment.

**Technologies:** Unity, C#

**Key features:**

* Custom wall-running system
* 3D player movement
* Ranged combat
* Enemy encounters

[View the Bounty repository](https://github.com/jhulk145/bounty)

### Intergalactic

A science-fiction adventure set aboard a compromised spaceship. The player explores different areas of the ship and fights the aliens that have invaded it.

**Technologies:** Unity, C#, Blender

**Key features:**

* Spaceship environment
* Player exploration
* Enemy combat
* Custom 3D assets

[View the Intergalactic repository](https://github.com/jhulk145/intergalactic)

## Unity Experiments

These smaller projects were created to explore individual gameplay mechanics and technical systems in Unity.

### 2D Platformer

A Unity prototype demonstrating 2D player movement, goal detection, and progression between stages. Reaching the goal takes the player to the next level.

**Skills demonstrated:**

* C# scripting
* 2D player movement
* Collision and trigger detection
* Unity scene management

[View the project files](experiments/2d-platformer)

### Idle AI Path Walker

A Unity experiment in which an AI-controlled character automatically follows a predefined path while idle.

**Skills demonstrated:**

* C# scripting
* Waypoint-based movement
* Automated NPC behaviour
* Basic AI navigation

[View the project files](experiments/idle-ai-path-walker)
